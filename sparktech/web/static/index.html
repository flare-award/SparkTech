Подключение телефона

SparkTech работает с телефоном только через официальный Android Debug Bridge. Кабель, отладка по USB и ваше подтверждение на экране телефона обязательны.

Как подключить телефон

4 шага
  1. 1
    Включите параметры разработчика
    Настройки → О телефоне → 7 раз нажмите «Номер сборки». На некоторых телефонах путь другой: Настройки → Система → О телефоне.
  2. 2
    Включите отладку по USB
    Настройки → Система → Для разработчиков → «Отладка по USB». На Xiaomi дополнительно нужна «Установка через USB» и отключение «Отладка по USB (уровень защиты)».
  3. 3
    Подключите телефон кабелем
    Кабель должен поддерживать передачу данных, а не только зарядку. В уведомлении «Использование USB» выберите «Передача файлов».
  4. 4
    Подтвердите запрос на экране телефона
    Появится диалог «Разрешить отладку по USB?» — нажмите «Разрешить». Если диалог не появился, отключите и снова подключите кабель.
Важно: обычного подключения по MTP недостаточно. Для доступа к файлам через ADB нужна именно отладка по USB. SparkTech не просит пароль от телефона, Google-аккаунта и не требует root.

Честность и ограничения

  • SparkTech видит только общую пользовательскую память, доступную через ADB без root.
  • Закрытые данные приложений и кэш приложений не сканируются и не очищаются автоматически.
  • Ничего не удаляется без подтверждения; автоочистки и «ускорителей» в программе нет.
  • Данные телефона не отправляются в сеть. Аналитики нет.

Удалить выбранные файлы?

Удаление с устройства необратимо. SparkTech не умеет восстанавливать файлы и не отправляет их в «корзину».

Системные файлы и данные приложений к удалению не допускаются. Если файл изменился после сканирования, SparkTech пропустит его и сообщит об этом.

Запустить выбранные действия?

SparkTech выполнит только отмеченные действия и проверит результат на устройстве. Отмена доступна только для действий с настройками.
